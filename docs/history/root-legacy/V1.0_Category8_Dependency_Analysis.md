## Three independent subsystems

Nothing in `collect/main.py` imports from `market/` or `migration/`. This means the untracked source code splits into three subsystems that don't need each other, only the shared `core/*` foundation:

**Subsystem A — Entity-Centric Migration v2 / analysis pipeline.** Required by `collect/main.py`'s `embeddings`/`sentiment`/`topics`/`topic_sentiment`/`topic_evolution` stages.

**Subsystem B — Market/BIST100 confirmatory analysis.** Self-contained; not imported by `main.py` at all. Reached only via its own scripts/tests.

**Subsystem C — Migration/backfill scripts.** One-off scripts from when the entity-centric migration was actually run against real data; not imported by anything else in the codebase.
